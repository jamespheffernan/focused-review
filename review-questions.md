# Weekly Review Questions

These questions guide your project reflection during weekly reviews. You can edit this file to customize the questions.

## First Review Questions
These questions are asked the first time you review a project:

### Purpose
**ID:** `q-purpose`  
**Type:** `text`  
**Question:** Why am I doing this project?

### Reality Check
**ID:** `q-reality`  
**Type:** `text`  
**Question:** Where am I right now with it?

### Next Action
**ID:** `q-next`  
**Type:** `text`  
**Question:** Is this the clearly defined, physical Next Action?

### Timeline
**ID:** `q-timeline`  
**Type:** `text`  
**Question:** What's the realistic timeline for this project?

### Alignment
**ID:** `q-align`  
**Type:** `text`  
**Question:** Does this align with higher-level goals?

### Engagement
**ID:** `q-engage`  
**Type:** `mood`  
**Question:** Am I engaged and motivated?

---

## Question Types
- `text`: Free-form text input
- `mood`: Emoji mood selector with 1-3 scale (1=😔 Low, 2=😐 Neutral, 3=😊 High)
